# Math_Game

# 🧮 Interactive Math Game for Kids

## Overview

**Interactive Math Game** is a fun and engaging web-based educational tool built with **React**. It is designed for children to practice basic arithmetic operations like addition and subtraction through randomly generated math questions. With real-time feedback, scoring, streak tracking, and celebratory animations, it encourages kids to keep learning and improving their mental math skills in a positive and playful environment.

---

## 🎯 Project Goals

- Help children strengthen their arithmetic skills.
- Encourage practice through gamification and visual rewards.
- Provide instant feedback to boost confidence and motivation.
- Use engaging UI and animations to enhance learning experience.

---

## 🔑 Key Features

- ✅ **Random Math Questions**  
  Generates age-appropriate addition and subtraction problems.

- ✅ **Instant Feedback**  
  Provides immediate responses for correct and incorrect answers.

- ✅ **Score & Streak Tracker**  
  Displays total score and number of consecutive correct answers.

- ✅ **Celebration Animation**  
  🎉 Emoji animation appears when the answer is correct.

- ✅ **Keyboard Shortcuts**  
  Pressing `Enter` submits the answer for quick interaction.

- ✅ **Responsive UI**  
  Built with Tailwind CSS to look great on any device.

---

## 🧠 How It Works

1. The app loads and generates a new random math problem.
2. The player inputs their answer and either presses **Enter** or clicks **Check Answer**.
3. If the answer is correct:
   - The score and streak counters increase.
   - Positive feedback and celebration animation are shown.
   - A new question is generated after a brief delay.
4. If the answer is incorrect:
   - Feedback encourages the player to try again.
   - Streak is reset to zero.
